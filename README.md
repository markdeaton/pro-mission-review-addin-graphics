# pro-mission-review-addin-graphics
This is an ArcGIS Pro add-in (Visual Studio 2022 project) to help with ArcGIS Mission post-mission review and analysis.

**Note:** Since this code was last updated, the ArcGIS Mission schema and API was updated in such a way that this code will no longer properly open missions. The code will need to be updated and tested before it can be used.

# Branches
## master
This branch is the original, created during the ArcGIS Pro 2.x years. That branch is obsolete and will not work with any 2.x version.
## Pro_3.x
This branch was updated to work with ArcGIS Pro 3.2. Use this for any further work.
